Uma aplicação desenvolvida para **gerenciar livros através de uma API REST e uma interface web**, permitindo cadastrar, consultar, editar e excluir registros.

O backend foi desenvolvido em **Python com FastAPI e SQLAlchemy**, utilizando **MySQL** para armazenamento dos dados.

O frontend, desenvolvido com **HTML, CSS e JavaScript**, realiza as requisições à API utilizando `fetch`.

O projeto foi construído em etapas: **configuração do ambiente e banco de dados → implementação do CRUD → validações e tratamento de erros → desenvolvimento da interface**.

### 🛠️ Tecnologias

**Python · FastAPI · Uvicorn · SQLAlchemy · PyMySQL · MySQL · HTML · CSS · JavaScript · XAMPP · Git/GitHub**
